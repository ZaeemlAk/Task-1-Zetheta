# Algorithmic Bias Audit for Credit Scoring Model

This project implements the audit scaffolding requested for a credit-scoring fairness assessment. It follows the project brief and keeps all analyses evidence-based.

## Project structure

- `src/` contains analysis modules.
- `tests/` contains unit tests.
- `reports/` contains generated reports.
- `figures/` contains charts and visual outputs.
- `tables/` contains data tables and summary outputs.
- `notebooks/` contains analysis notebooks.

## Important note

The project brief requires real dataset inspection before final conclusions. The workspace currently does not contain the actual credit dataset or project brief files beyond the audit prompt. The provided code therefore implements the audit architecture, data-loading utilities, and analysis scaffolding without fabricating results.

## Validation

Run tests with:

```bash
python -m pytest -q
```
